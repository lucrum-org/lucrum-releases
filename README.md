## Install

```sh
brew tap lumen-terminal/lumen
brew install --formula lumen-terminal
```

Or:

```sh
curl -fsSL https://raw.githubusercontent.com/lumen-terminal/lumen-terminal/lumen-terminal/scripts/install-remote.sh | bash
```
